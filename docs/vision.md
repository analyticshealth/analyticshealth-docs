# Product Vision

AnalyticsHealth aims to answer a simple question:

> *“What can my health data tell me today?”*

Instead of dashboards, charts or metrics overload, the platform focuses on **conversational insights** powered by LLMs.

## Key Ideas
- Data is ingested automatically and asynchronously
- Users interact via natural language
- The system explains trends, correlations and anomalies
- No real-time constraints — D-1 data is acceptable

## Target Evolution
- Today: single user (personal use)
- 6 months: 10–50 users
- 12+ months: hundreds of users

The architecture is designed to scale **organisationally and technically** without major refactors.
